Projektplan – ERP Implementation

BC/TRIMIT Implementering · Interaktiv Gantt med ressourcefilter

Opdateret: 6. maj 2026

⚠️ Demo data — Du ser eksempeldata. Klik 📂 Import Excel for at indlæse dine egne projektdata.

📖 Brugervejledning – Projektplan Dashboard

Se den fulde dokumentation: Projektplan Dashboard Guide

1. Overblik

Interaktivt web-dashboard til styring og visualisering af ERP-implementeringsprojekter. Kører i browseren via https://trimit-projektplan-viewer.web.app. Kræver kun en Google-konto.

2. Brugerflow

🔐 Google Login → 📁 Projektliste → + Opret / Åbn projekt → 📂 Import Excel → 📊 Dashboard

3. Login og projekter

  • Google Sign-In – Log ind med din Google-konto
  • Mine projekter – Viser kun projekter du har oprettet
  • Alle projekter – Viser alle brugeres projekter (deling er automatisk)
  • + Nyt projekt – Opretter et tomt projekt til Excel-import
  • 📊 Demo-projekt – Vis eksempeldata uden at gemme
  • 🗑 Slet – Kun ejeren kan slette et projekt

4. Import af data

Klik 📂 Import Excel og vælg en .xlsx/.xls-fil. Data læses fra det første ark. Kolonner genkendes automatisk via nøgleordsmatching.

  • Begin-Total → Opretter en faseoverskrift
  • Posting / blank → Opgave under aktuelle fase
  • End-Total / Total → Ignoreres

Kun Description er påkrævet. Øvrige kolonner: Activity No., Type, Resource No., Resource Group No., Estimated Hours, Entered Hours, Remaining Hours, Starting Date, Ending Date, % Complete, Status, Dependencies.

5. KPI-oversigt

  • Estimerede timer – Sum af budgetterede timer
  • Forbrugte timer – Registrerede timer
  • Resterende timer – Timer der mangler
  • Samlet progression – Forbrugt / Estimat i procent
  • Forsinkede – Opgaver med overskredet slutdato (klik for filter)
  • Økonomi – Budget, forbrugt og resterende beløb (1.250 kr/t)

6. Visninger

  • Faser og opgaver – Hierarkisk trævisning med expand/collapse, timer, progress-bar, status, resource
  • Gantt-tidslinje – Visuelle bjælker per fase/opgave. "I dag" markeret med rød linje
  • Ressource-belastning – Bjælkediagram med timer og % forbrug per resource/fase/gruppe
  • Kapacitets-heatmap – Tidsfordeling over måneder/uger med farvekodning

7. Filtrering

  • Resource – Filtrer til én person
  • Fase – Zoom ind på én fase
  • Status – Multi-select: Igangværende, Afsluttet, Ikke startet
  • Søg – Fritekstsøgning på opgavenavn eller resource
  • Fra/Til – Juster Gantt-tidslinjen
  • Vis datoer / Vis ID – Toggle ekstra kolonner

8. Grupperinger

Ressource-belastning, Heatmap og Gantt kan grupperes: Fase, Ressource, Res.Group, Overordnet fase.

9. Afhængigheder

Aktivér "Vis afhængigheder" for at se 🔗-badges i træet og SVG-pile i Gantt fra forudsætningens slut til den afhængige opgaves start.

10. Eksport og gem

  • 📥 CSV – Download filtreret view som semikolon-separeret fil (Excel-kompatibel)
  • 💾 Gem – Gem projektdata til skyen (Firestore). Sker automatisk ved import.
  • ◀ Projekter – Gå tilbage til projektlisten

11. Teknisk

Frontend: ren HTML/JS. Excel-parsing: SheetJS (CDN). Auth: Firebase/Google. Database: Cloud Firestore. Hosting: Firebase Hosting.
